# 工作原则

## 1. 先定边界，再生成

先确认规则，不要直接生成目标模拟器。

至少要确认这些问题：

- 历史时期、起始时间、地理范围
- 主角是谁，玩家是否等于该角色
- 真实性模式是"严格史实 / 合理架空 / 混合奇幻"
- 用户追加设定是什么，它如何改变底层规则
- 每回合粒度是日、旬、月、季还是事件节点
- 输出更偏"游戏回合日志"还是"小说正文"

详见 `references/interview-checklist.md`。

## 2. 史实、推演、设定必须分层

生成的目标模拟器必须区分：

- 史实锚点：已知历史时间、人物、制度、地理、重大事件
- 合理推演：在史实约束下的行为推断与连锁反应
- 用户设定：例如系统、修仙、穿越知识、超自然势力
- 演化结果：玩家行动与世界状态共同产生的新历史

不要把这四层混成一个模糊叙事。

## 3. 天气不是装饰

天气和气候必须影响至少一部分核心系统：

- 粮食与税赋
- 行军与交通
- 疾病与民情
- 战事节奏
- 地方治安

如果用户明确强调气候，例如明末小冰河期，生成的目标模拟器必须把它写进长期扰动规则，而不是只写成场景描写。

## 4. 记录必须可沉淀

目标模拟器的每回合都要留下两层记录：

- 结构化账本：时间、地点、天气、事件、行动、结果、状态变化
- 小说化正文：把这一回合演绎成可连续阅读的叙事片段

玩家玩完一局后，记录应当足以整理成完整中短篇小说或编年史。

## 5. 史料来源必须可追溯

凡是被写入目标模拟器硬规则的历史断言，都必须能追溯到可靠来源。

至少做到：

- 关键人物判断有来源依据
- 关键世界事件有来源依据
- 气候、灾荒、制度规则有来源依据
- 有争议的内容明确标注争议或置信度

禁止把以下内容直接当作史料：

- 无引用的 AI 总结
- 自媒体二次转述且不给原始出处
- 营销号、洗稿站、匿名搬运文
- "据说""有人讲过"式传闻

来源规范见 `references/source-policy.md`。

## 6. 信息不对称是硬规则

目标模拟器必须默认采用非上帝视角运行。

这意味着：

- 世界主持器维护全局真相与隐藏状态
- 每个角色只知道自己应知的部分
- 每个势力只掌握本势力可得信息
- 主角只知道自己亲历、被汇报、被侦知、被揭发到面前的内容

禁止出现以下情况：

- 所有人都同步知道幕后密谋
- 玩家直接看到底下人私下账本
- 角色根据自己不可能知道的信息行动

只有天气与天灾这类世界级扰动天然不受人控制，但其详细影响仍然可以分层暴露。若用户引入能干预天象的特殊设定，再单独改写。

信息规则见 `references/knowledge-model.md`。
