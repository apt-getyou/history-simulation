### 性格变化规则

1. **渐进变化**：教育/环境影响，每季度 +1~3
2. **里程碑变化**：重大事件触发，单次 +/-5~20
3. **回归趋势**：极端值（>80 或 <20）有向50回归的倾向，每季度 +/-1
4. **上限**：单次变化不超过 +/-20，单季度总变化不超过 +/-10

### 教育效果结算

每季度末结算一次教育效果：

```
对每个 教师条目:
  1. 基础效果 = 科目定义的维度变化
  2. 教师修正 = 教师威望 x1.0~1.2
  3. 关系修正 = 关系亲密额外 +1 trust
  4. 性格传导 = 教师核心维度额外 +0.5
  5. 应用到性格维度
  6. 写入 state.json growth.education_progress
```

### 教育中断

以下情况中断教育：
- 教师离开（出征、调任、死亡）
- 主角迁移（搬迁到其他城市）
- 战乱（战事波及主角所在位置）
- 用户主动选择更换教师/科目

中断后自动寻找替代教师（从 active 人物中匹配），如无匹配则暂停该科目。

## 自动推进机制

### 适用条件

当 `simulation_mode` 为 `growth_infancy` 时（年龄 0-6 岁），启用自动推进：

1. 跳过回合流程步骤 8（读取主角行动）
2. GM自动决定主角行为（基于性格和环境）
3. 每回合跨越季度或半年（而非月）
4. 输出侧重于成长叙事而非决策

### 自动推进回合流程

1. 推进日期（季度/半年）
2. 结算天气和气候
3. 结算事件（仅旁观事件和成长事件）
4. 加载人物（身边人）
5. 结算身边人物行为
6. 结算幕后动作
7. **自动生成主角行为**（基于性格和年龄）
8. 结算教育效果（如有教师）
9. 更新状态和性格维度
10. 输出成长叙事
11. 检查阶段转换条件
12. 写入记录和 state.json
