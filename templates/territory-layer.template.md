# 领土控制与可视区域

## 概述

本文件定义地图系统的 L2（领土控制）和 L3（可视区域）两层。L2 每回合动态更新，L3 基于信息不对称原则维护认知边界。

## L2 领土控制

### 区域控制状态

每个区域维护以下控制状态：

```yaml
territory:
  region_id: "{{REGION_ID}}"
  controller: "{{势力名}}"
  control_strength: 0.0           # 0-1，控制力度
  sub_control:                     # 多势力分治时使用
    - controller: "{{势力A}}"
      share: 0.6
      areas: ["{{区域部分}}"]
    - controller: "{{势力B}}"
      share: 0.4
      areas: ["{{区域部分}}"]

  garrison: 0                      # 驻军数量
  garrison_morale: 0               # 驻军士气 0-100
  garrison_loyalty: 0              # 驻军对控制者的忠诚 0-100

  local_loyalty: 0                 # 当地民心 0-100
  tax_rate: 0.0                    # 实际税收上缴率 0-1
  tax_collection_efficiency: 0.0   # 征税效率 0-1

  recent_battles: []               # 近期战事记录
  occupation_date: ""              # 当前控制者占领时间
  control_history: []              # 控制权变更历史
```

### 控制强度等级

| 控制强度 | 等级 | 税收 | 征兵 | 情报 | 说明 |
|----------|------|------|------|------|------|
| 0.8-1.0 | 牢固控制 | 100% | 正常 | 完整 | 核心领土 |
| 0.5-0.8 | 稳定控制 | 70% | 有限 | 大部分 | 普通领土 |
| 0.3-0.5 | 松散控制 | 40% | 困难 | 模糊 | 新占领/边境 |
| 0.1-0.3 | 名义控制 | 10% | 几乎无 | 极少 | 仅有驻军 |
| 0-0.1 | 失控 | 0% | 无 | 无 | 实际无政府状态 |

### 控制强度变化因素

**增强因素：**
- 长期和平治理（每连续 1 年无战事 +0.02）
- 兴修水利、开垦农田（一次性 +0.05-0.10）
- 派驻得力官员（持续 +0.01/年）
- 镇压叛乱成功（一次性 +0.05，但民心 -10）
- 赈灾及时（民心 +10，控制力 +0.03）

**削弱因素：**
- 战争破坏（每场重大战役 -0.10-0.20）
- 官员腐败/无能（持续 -0.02/年）
- 饥荒/天灾无赈济（民心 -20，控制力 -0.10）
- 敌方渗透/煽动（-0.05，视敌方投入）
- 驻军调离（-0.10-0.20，视驻军比例）

### 战争结算与领土变更

```
战争结算流程:
1. 攻方在某区域发动进攻
2. 判定战斗结果（攻方兵力、补给、士气 vs 守方兵力、地形加成、士气）
3. 战斗结果影响控制强度:
   - 攻方大胜: 守方 control_strength -= 0.4-0.6
   - 攻方小胜: 守方 control_strength -= 0.2-0.3
   - 守方大胜: 攻方退兵，control_strength 不变
   - 持平: 双方消耗，守方 control_strength -= 0.1
4. 当 control_strength 降至 0 以下:
   - 控制权转移给攻方
   - 新控制强度 = 攻方剩余战力比例 * 0.5（上限 0.6，新占领不可能牢固）
5. 补给线检查:
   - 新占领区域必须与己方已有领土相邻
   - 若不相邻，control_strength 上限 0.3（飞地，难以维持）
```

## L3 可视区域（认知边界）

### 信息可见性规则

主角对每个区域的可见性分为四个等级：

| 可见性 | 条件 | 可见信息 |
|--------|------|----------|
| **完整** | 本势力牢固/稳定控制的区域 | 控制者、兵力、民心、税收、资源产出、官员 |
| **部分** | 本势力松散控制，或相邻区域的友方领土 | 控制者、大致兵力、近期战事 |
| **模糊** | 有外交接触的区域，或有细作渗透的区域 | 控制者、方向性判断（强/弱） |
| **未知** | 从未接触过的区域 | 无任何信息，地图上显示为"未探明" |

### 可见性提升途径

| 途径 | 效果 | 条件 | 风险 |
|------|------|------|------|
| 派遣细作 | 目标区域可见性提升一级 | 有合适人选、对方区域有入口 | 细作可能被捕/暴露 |
| 派遣使节 | 目标区域可见性提升至"模糊" | 双方有基本外交关系 | 使节可能被扣留 |
| 商队往来 | 沿途区域可见性提升至"部分" | 贸易路线安全 | 商队可能被劫 |
| 流民/逃兵报告 | 获得特定信息片段 | 有流民/逃兵到达己方领土 | 信息可能过时或不准确 |
| 军事侦查 | 边境区域可见性提升至"部分" | 有骑兵/斥候可用 | 可能遭遇伏击 |

### 主角位置的影响

主角当前所在区域的可见性自动为"完整"。主角移动时，沿途经过的区域可见性临时提升至"部分"。

## 使用要求

- L2 每回合结算时必须更新，与战争引擎、外交系统联动
- L3 必须与知晓模型（`11-knowledge-model.md`）联动，不单独运作
- 战争结果必须同时更新 L2 和 L3（占领新区域后才能看到内部信息）
- 控制强度低于 0.3 的区域可能在事件引擎中触发"叛乱""脱离"事件
- 主角的决策只能基于 L3 可见的信息，不能利用 L2 的完整数据
