# 知晓模型

## 总原则

- 世界主持器维护全局真相
- 玩家只看到主角当前可知信息
- 角色按各自知情范围行动
- 隐藏信息必须经由传播链或暴露条件进入玩家视野

## 信息层级

| 标签 | 含义 | 默认可见对象 |
|------|------|--------------|
| global_truth | 世界真实发生 | 世界主持器 |
| private_known | 少数当事人知道 | 相关个人 |
| faction_known | 势力内部知道 | 相关势力 |
| public_known | 社会面公开 | 所有人 |
| player_known | 主角当前知道 | 玩家 |

## 主角知晓渠道

- 亲见
- 面奏
- 密报
- 巡查
- 查账
- 审讯
- 流言
- 事件爆发

## 信息到达判定规则

信息从发生到主角知晓需要经过传播链。每条信息有基础延迟和修正因子。

### 基础延迟表

| 传播渠道 | 基础延迟 | 可靠性 | 适用场景 |
|----------|----------|--------|----------|
| 亲见 | 0 回合 | 确认 | 主角在场的事件 |
| 面奏/密报 | 0-1 回合 | 确认 | 朝堂渠道 |
| 军报 | 1-2 回合 | 确认 | 战场消息 |
| 官员奏报 | 1-2 回合 | 高 | 地方行政消息 |
| 流言 | 2-4 回合 | 低 | 民间消息 |
| 事件爆发 | 0 回合 | 确认 | 影响直接到达的事件 |
| 商人情报 | 2-3 回合 | 中 | 贸易路线消息 |
| 间谍回报 | 1-3 回合 | 中-高 | 需要间谍网络覆盖 |

### 修正因子

| 因子 | 效果 | 说明 |
|------|------|------|
| 距离远（>500里） | 延迟 +1 | 信息传递时间增加 |
| 战乱区域 | 延迟 +1~2 | 传递链路不稳定 |
| 主角威望高 | 延迟 -1（最低0） | 信息优先送达 |
| 相关势力有意隐瞒 | 延迟 +2~4 | 刻意阻断 |
| 季节（冬季） | 延迟 +1 | 交通困难 |

### 判定流程

```
事件发生 → 确定初始可见范围 → 查传播渠道 → 计算基础延迟 → 应用修正因子 → 确定 ETA 回合
```

### 可靠性衰减

| 延迟回合数 | 可靠性变化 |
|-----------|-----------|
| 0-1 | 无衰减 |
| 2 | 可能失真（10%概率细节错误） |
| 3 | 可能失真（25%概率细节错误） |
| 4+ | 可能失真（40%概率细节错误） |

## 输出约束

- 可以提示玩家”你暂不知真相”
- 不可以提前透出幕后完整过程
- 不可以让角色根据不可能知道的信息行动
- 信息到达时必须标注来源渠道和可靠性
