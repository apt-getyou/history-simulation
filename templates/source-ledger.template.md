# 来源账本

## 关键断言表

| 断言ID | 断言/规则 | 类别 | 来源等级 | 具体出处 | 原文引用 | 用途 | 置信度 | 偏倚提示 | 叙事依赖 | 争议说明 |
|--------|-----------|------|----------|---------|---------|------|--------|---------|---------|---------|
| {{id}} | {{claim}} | person/event/climate/institution | A/B | {{source_detail}} | {{exact_quote}} | {{usage}} | high/medium/low | {{bias_note}} | {{narrative_dep}} | {{dispute}} |

## 字段说明

### 断言ID

每条断言的唯一标识。格式为 `A{NNN}`（有证据支撑）或 `I{NNN}`（推断类）。

与 `data/sources/evidence/{entity}-evidence.json` 中的 ID 一一对应。

### 原文引用

从原始文献中摘录的原文，确保可追溯。

示例：
- `"诸葛亮字孔明，琅琊阳都人也"`
- `"识治之良才，管、萧之亚匹矣"`

### 偏倚提示

标注该断言涉及的来源偏倚。常见类型：

| 偏倚类型 | 说明 | 示例 |
|----------|------|------|
| 政治立场 | 作者受政治立场影响 | 陈寿西晋立场，以魏为正朔 |
| 正统观念 | 作者的正统观影响记载 | 尊汉/尊魏的不同叙事 |
| 文学塑造 | 文学作品为情节需要塑造 | 演义为塑造人物形象而虚构情节 |
| 时代局限 | 作者时代认知局限 | 汉晋时期对疾病、天象的认知 |
| 叙事传统 | 继承某一叙事传统 | 后世史书继承前代记载 |
| 作者偏好 | 作者对某人物的偏好 | 陈寿对诸葛亮"盖应变将略，非其所长"的评价 |

### 叙事依赖

标注该断言涉及的来源间是否存在传抄/依赖关系。

| 标记 | 含义 |
|------|------|
| `independent` | 来源独立，无依赖关系 |
| `dependent: {source_id}` | 依赖指定的来源 |
| `suspected` | AI 检测到嫌疑但用户未确认 |
| `pending` | 待检测 |
| `N/A` | 单一来源，不适用 |

## 断言强度说明

| 强度 | 说明 | 模拟器中的处理 |
|------|------|-------------|
| strong | 一手史料直接支持，或两条独立来源交叉支持 | 可写入硬规则 |
| weak | 仅有单一二手来源，或来源间存在冲突 | 标注为"倾向""可能" |
| disputed | 来源间不可调和矛盾 | 标注所有版本 |
| fiction | 文学创作/演义虚构 | 按蓝本策略决定是否纳入 |
| inferred | 无直接史料，从行为/环境推断 | 标注推断逻辑，不可作为硬规则 |

## 使用说明

- 每条关键人物规则至少对应一条来源
- 每条关键世界事件至少对应一条来源
- 气候、制度、财政规则优先使用 A 级来源
- 没有可靠来源的内容，不进入硬规则
- 叙事依赖为 `dependent` 或 `suspected` 的断言，交叉验证等级自动降一级

## 证据链文件

完整的证据链数据（含原文引用、偏倚标注、交叉验证详情）存储在：

`data/sources/evidence/{entity}-evidence.json`

来源账本为证据链的摘要视图。需要查看完整溯源信息时，通过断言ID检索对应的 evidence.json 文件。
